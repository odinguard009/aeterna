# Aeterna doc convention

One home per kind of content; other files link it instead of repeating it.

| Kind | Home |
|---|---|
| Rules for agents (short, always loaded) | `CLAUDE.md`; it routes to the rest |
| Topic guides for agents (release, tokens, card data, plans) | `docs/ai/*.md` |
| How the product fits together | `docs/ARCHITECTURE.md` |
| One mechanic: rule source, page, decision, tests, open points | `docs/mechanics/<mechanic>.md` |
| Rule notes and coverage | `docs/manual-notes.md`, `docs/rules-coverage.md` (rows link the mechanic file) |
| Generated reports (rewritten by a tool) | `docs/reports/` (first line names the tool) |
| Release notes | `CHANGELOG.md` (newest first; GitHub Releases are made from it by `.github/workflows/release.yml`) |
| Front page | `README.md` (short, under 120 lines, no release notes; screenshots in `docs/images/` from `node tools/screens.mjs`) |
| Raw inputs (exports, indexes) | `data/sources/` (not in the light clone), `data/index/` |
| Card data | `data/import` (staging), `data/cards` (playable) |
| Workflows for one kind of task | `.claude/skills/<name>/SKILL.md` |
| Open work | `docs/ai/roadmap-open.md` and GitHub Issues |

Rules:
- Every doc gets one line in `docs/README.md` (hand-written or "generated by <tool>"). A new generated file starts with a line naming its tool and "do not edit".
- Never edit a generated file by hand; change its tool and rerun it.
- Code and docs change together in the same commit; a moved file has zero hits for its old path (`grep -rn` over `tools src tests .github .githooks .claude docs CLAUDE.md README.md package.json`).
- No rule in two places: when a rule moves, the old place keeps only a link.
- Paths read from outside a clone never move: `tools/session_gate.sh`, `tools/session_start.sh`, `index.html`, `docs/roadmap.html`, `docs/progress.html`, `.githooks/`, `.github/workflows/`.
- A mechanic file is started when a session touches that mechanic (no separate pass). Template: title, Source (manual + page), Decision, Engine (functions, flags), Tests, Open.
- Public text keeps the neutral codename (brand guard).
