# Card information sources (checked 2026-10-13)

Cloud sandbox: shell has no internet except package registries/GitHub. WebFetch/WebSearch only.

| Source | Status from the cloud | Use |
|---|---|---|
| battle-spirits.fandom.com (English, fan-translated) | Blocked: pages fail with "error while fetching" (one page worked once). Appears in search results but cannot be read. | Best text source. Needs a user screenshot / pasted text, or the user's PC linked, or the host allowed by the org. |
| yuyu-tei.jp (Japanese shop) | Works. Set page: /sell/bs/s/bsNN ; card page: /sell/bs/card/bsNN/ID | Card number, type, colour, cost, level cores, trait, Japanese effect text (tool summarises long text). |
| battlespirits.com (official) | Opens, but the card list is JavaScript-only: no data. | Rules PDFs, banned list, notices. |
| bssdb.dev, battlespirits-saga.com | Reachable, but cover Battle Spirits Saga (international), not BS74-BS76. | Not useful for Eternal/Contract cards. |
| limitlesstcg.com/bandai/bss | Saga only. | Not useful. |

Method: verify type/colour/cost/levels/effects of every card against yuyu-tei; ask the user for Fandom screenshots for unclear text.
