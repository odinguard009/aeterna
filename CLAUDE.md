# Aeterna — working agreement (loaded automatically; never re-read it)

Single-file web simulator for a trading card game vs CPU (Windows + Android), modelled on aegis-digi.online. `index.html` is **built from `src/`, never edited by hand**. Unofficial non-commercial fan project; card names, text and trademarks belong to their owners. Repo odinguard009/aeterna (public; history before v0.57.0 stays in the owner's private vault repo): call `add_repo` once, then ONE light clone (generous timeout, never two git operations at once): `git clone --depth 1 --filter=blob:none --sparse <url> aeterna && git -C aeterna sparse-checkout set --no-cone '/*' '!/data/sources/' '!/docs/reports/red-cards-check-table.html'`. Then one call: `bash tools/session_start.sh` (overlap guard, hooks, baseline `npm run -s loop`, version, last 5 commits, Next line, playable count, open issues; `--with-sources` adds `data/sources`). Backlog: GitHub Issues via `gh api repos/odinguard009/aeterna/...`. Test I30 skips itself in the light clone.
