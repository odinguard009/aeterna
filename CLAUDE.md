Single-file web simulator for a trading card game vs CPU (Windows + Android), modelled on aegis-digi.online. `index.html` is **built from `src/`, never edited by hand**. Unofficial non-commercial fan project; card names, text and trademarks belong to their owners. Repo odinguard009/aeterna (public; history before v0.57.0 stays in the owner's private vault repo): call `add_repo` once, then ONE light clone (generous timeout, never two git operations at once): `git clone --depth 1 --filter=blob:none --sparse <url> aeterna && git -C aeterna sparse-checkout set --no-cone '/*' '!/data/sources/' '!/docs/reports/red-cards-check-table.html'`.
